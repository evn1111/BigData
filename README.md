Яшков Иван Александрович. Курс «Анализ данных: машинное обучение и BigData для ЗО», Павлова Е.А.

Выполнены оба уровня задания для получения допуска к экзамену.

- [Готовая книга Excel](outputs/01a0ebfe-sales/sales_analysis.xlsx) — формулы, фильтры, рейтинги, сводная таблица и четыре диаграммы.
- [Отчёт](results/report.md) — результаты и выводы.

- `sales_analysis.py` — расчёт показателей и проверка исходных данных на Python.
- `results/` — таблицы расчётов в CSV и краткая сводка JSON.

## Что находится в Excel

Лист «Анализ»: выручка, топ-5 товаров, категории, регионы, топ-10 заказов и средние цены.

Лист «По месяцам»: сводная сумма Total по Month, выручка категорий, оценка роста и два графика динамики.

Лист sales_data: все 1200 записей отсортированы по дате, включены фильтры, добавлены Total, Month и RevenueRank. Даты хранятся как даты Excel. Total рассчитан по формуле Price × Quantity. RevenueRank используется для рейтинга заказов.

После изменения продаж формулы пересчитываются автоматически. Сводную обновляют через «Данные → Обновить всё». Результаты в отчёте и CSV относятся к первоначальному файлу.

## Пересчитать анализ на Python

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python sales_analysis.py
```

Скрипт пересчитывает CSV и JSON. Готовая Excel-книга уже приложена; Python не перезаписывает её и текст отчёта.
