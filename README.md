Преподаватель — Павлова Е.А. Язык — Python.

## Задания

| Папка | Задание | Ветка |
| --- | --- | --- |
| Корень ветки | Сегментация клиентов методом K-средних | `assignment-1` |

Каждое задание находится в отдельной ветке, созданной от `main`. Ветки заданий не объединяются: файлы каждого задания лежат в корне своей ветки.

Папки следующих заданий создаются по мере выполнения. Первое задание пока доступно в ветке `assignment-1`.

## Запуск первого задания

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
MPLBACKEND=Agg .venv/bin/python customer_segmentation_kmeans.py
```

Исходные данные находятся в `data/`, отчёт — в `results/report.md`, графики — в `results/figures/`. Учебные шаблоны и материалы курса в репозиторий не включены.
