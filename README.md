# Задание №4 — нейронная сеть для прогнозирования покупки

Яшков Иван Александрович. Курс «Анализ данных: машинное обучение и BigData для ЗО». Преподаватель — Павлова Е.А.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python purchase_prediction.py
```

## Файлы

- `purchase_prediction.py` — обучение и сравнение моделей;
- `data/customers.csv` — неизменённые данные из задания №1;
- `data/customers_with_purchase.csv` — данные с учебным признаком покупки;
- [results/report.md](results/report.md) — объяснение работы и выводы;
- `results/metrics.csv` — метрики обеих моделей;
- `results/learning_history.csv` — результаты по эпохам;
- `results/test_predictions.csv` и `results/errors.csv` — прогнозы и ошибки;
- `results/figures/` — графики обучения, матрицы ошибок и ROC-кривые.

В исходном задании №1 была кластеризация без целевой переменной покупки. В №4 добавлена искусственная покупка в следующем периоде и отдельно построена логистическая регрессия для сравнения. Это допущение описано в отчёте; оно не заменяет исходное первое задание.

Нейронная сеть: accuracy 0,7417, F1 0,6517. Регрессия: accuracy 0,7250, F1 0,6207. По ROC-AUC немного лучше регрессия. Обе модели проверены на одних и тех же 120 клиентах.
