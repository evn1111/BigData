## Запуск первого задания

```bash
python3 -m venv .venv
git switch assignment-1
.venv/bin/python -m pip install -r requirements.txt
MPLBACKEND=Agg .venv/bin/python customer_segmentation_kmeans.py
```

Данные находятся в `data/`, отчёт — в `results/report.md`, графики — в `results/figures/` соответствующей ветки. Учебные шаблоны и материалы курса в репозиторий не включены.
